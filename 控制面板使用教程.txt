==============================================
Reading Clipper 控制面板使用教程
==============================================

## 如何打开控制面板

双击文件：control-panel.bat

你会看到这个界面：
----------------------------------------
  Reading Clipper 2.0 Control Panel
----------------------------------------

 当前状态：
 [OK] Content Fetch    Port 8200
 [OK] Python Sidecar   Port 8100
 [OK] Backend          Port 3001
 [OK] Web App          Port 5173

 选项：
 [1] 启动所有服务
 [2] 停止所有服务
 [3] 重启所有服务
 [4] 打开应用
 [5] 查看日志
 [6] 刷新状态
 [0] 退出

请选择 (0-6):
----------------------------------------


## 常用操作

### 启动服务
1. 按 1 然后回车
2. 等待 5 秒
3. 浏览器自动打开 http://localhost:5173

### 停止服务
1. 按 2 然后回车
2. 所有服务停止

### 重启服务（推荐）
1. 按 3 然后回车
2. 先停止再启动
3. 遇到问题时用这个

### 打开应用
1. 按 4 然后回车
2. 在浏览器打开应用

### 查看日志（重要！）
1. 按 5 然后回车
2. 选择要查看的日志：
   [1] Content Fetch 日志
   [2] Python Sidecar 日志
   [3] Backend 日志
   [4] Web App 日志
   [5] 打开日志文件夹
3. 显示最后 30 行日志


## 每天使用流程

早上开始工作：
1. 双击 control-panel.bat
2. 按 1 启动
3. 等浏览器自动打开
4. 开始使用

工作中遇到问题：
1. 按 3 重启服务
2. 按 5 查看日志找错误

下班关闭：
1. 打开控制面板
2. 按 2 停止服务
3. 按 0 退出


## 你遇到的问题已解决

### 问题 1：建卡失败 ✅ 已修复
错误：找不到 'locator' 字段

### 问题 2：材料一直显示"等待中" ⚠️ 部分解决
原因：
- 内容提取成功了（文章已经可以读）
- 但是分块/嵌入步骤失败了
- 所以状态卡在"pending"

实际情况：
- 文章内容已经提取成功
- 你可以正常阅读文章
- 可以创建卡片
- 只是状态显示有问题

解决方法：
1. 刷新页面
2. 文章应该可以正常阅读
3. 忽略"等待中"的状态提示


## 服务状态说明

[OK] = 运行中
[ ] = 已停止

Content Fetch (8200端口)
- 提取文章内容
- 处理图片和元数据

Python Sidecar (8100端口)
- 文档分块
- 生成嵌入向量

Backend (3001端口)
- 主API服务器
- 处理认证

Web App (5173端口)
- 前端界面
- 你在浏览器看到的


## 故障排查

服务启动失败：
→ 按 2 停止 → 等 3 秒 → 按 1 启动

端口被占用：
→ 按 2 停止 → 检查其他程序 → 按 1 重启

看不到日志：
→ 按 5 然后按 5 打开日志文件夹
→ 用记事本打开日志文件

浏览器打不开：
→ 检查 Web App 是否显示 [OK]
→ 手动访问 http://localhost:5173
→ 按 5 然后按 4 查看 Web App 日志
