## S1 第一印象与品牌

### 观察

**品牌传达**: "Verity EVIDENCE STUDIO" — logo 是天秤（求真/平衡），副标题 "EVIDENCE STUDIO"。品牌名和视觉统一传达"严谨、证据驱动"的气质，与产品定位高度吻合。

**主色调**: 暖米色背景（约 #f4f2ec），深棕色文字，蓝色 CTA 按钮。整体偏学术/研究工具气质，避免了 SaaS 产品常见的冷蓝色调，有辨识度。

**首页空状态** (截图 01-home):
- 标题 "Your Research" + 副标题 "选择一个 Topic 进入工作区" — 明确引导
- 空状态图标（文件夹）+ 文字 "还没有 Topic，点击上方「新建 Topic」开始研究" — 引导清晰
- 蓝色 "＋ 新建 Topic" CTA 在右上角，位置醒目
- 底部显示登录用户 (test@verity.dev) + 登出按钮
- 右下角紫色浮动聊天气泡 — 提供随时 AI 对话入口

**改进建议**:
- P2: "Your Research" 用英文，但其余 UI 全中文 — 建议统一语言（标题也用中文"我的研究"）
- P2: 空状态可以更丰富 — 比如加一个 "30 秒快速开始" 教程链接或示例 Topic

### 评分: 4/5
品牌感强，空状态引导清晰。语言混用是小瑕疵。

## S2 导航与信息架构

### 侧栏结构
```
RESEARCH
  研究主页     ← Topic 列表（首页）
  AI 助手      ← 全局聊天（自由模式）

LIBRARY
  材料库       ← 来源库（URL/文件/文本）
  信息源       ← RSS 订阅管理

SETTINGS
  设置         ← AI 模型 / RSS / 信息源 / 导出
```

### 观察

**功能可发现性**:
| 功能 | 难度 | 备注 |
|------|------|------|
| 创建 Topic | 1 | 首页 CTA 醒目 |
| 导入材料 | 1 | 材料库页 CTA 清晰 |
| AI 对话入口 | 1 | 侧栏 + 浮动气泡，双入口 |
| 画板添加节点 | 2 | 需进入 Topic → 点"创建根问题" |
| 查看证据平衡 | 2 | 需进入 workspace → 看研究健康度面板 |
| 启动 Research Run | 3 | 不明显，需知道在 chat 中输入特定请求 |

> 1=一眼找到 / 2=需探索 / 3=需引导

**导航问题**:
- P1: "信息源" 在侧栏 LIBRARY 下 和 设置 > "信息源" tab 指向同一页面（RSS 订阅管理），造成路径重复。用户可能困惑两个入口的区别
- P2: "AI 助手" 和 "研究主页" 的关系不直观 — 进入 Topic workspace 后有独立的 AI chat panel，与全局 "AI 助手" 的对话是隔离的，但 UI 没有明确说明
- P2: "任务" 功能位于 AI 助手页面的 tab（对话/任务），而不是独立导航项 — 可能会被忽略

### 评分: 3.5/5
核心功能易发现，但信息源路径重复、chat 隔离关系不透明。

## S3 AI 对话体验

### 测试场景

**场景 1: 自我介绍** (截图 10-chat-ai-reply)
- 输入: "你好，你是谁？能帮我做什么？"
- 回复质量: 优秀
  - 自称 "Verity（求真），一个'证据驱动'的研究助手" — 品牌一致
  - 列出 4 大能力: 快速找证据与出处、总结对比与核验、结构化推进研究、输出可交付内容
  - 结尾引导: "如果你告诉我你现在在研究什么...我就可以直接开始" — 很好的对话引导
  - 无 UUID、工具名、function_call 等内部信息泄漏
  - Markdown 渲染: 有序列表 + 无序列表渲染正确

**场景 2: 研究假设生成** (截图 13-workspace-ai-reply)
- 在 workspace 中输入: "帮我提出 2 个关于 AI 测试的研究假设"

- P1: 模式切换（聊天/代理/自动）的区别没有解释，新用户不知道选哪个
- P2: 对话标题是否可手动编辑？未发现编辑入口

## S10 Top 改进建议

### P0 — 阻塞核心价值

1. **AI 应在 Workspace 中自动操作画板**: 当用户在 workspace chat 中请求"提出假设""添加证据"时，AI 应调用 propose_board_changes 创建 DraftNode，而不是仅文字回复。这是 Verity "AI 驱动研究" 的核心差异化，当前未被触发。建议检查 draftEngine 和 chat orchestrator 的 tool selection 逻辑 — 可能是 surfaceContext 未正确传递 boardId，或 prompt 中未充分引导模型使用画板工具。

2. **AI 等待状态缺反馈**: 发送消息后到 AI 回复之间（可能 5-30 秒），UI 完全静止。用户不知道请求是否在处理。至少需要一个 typing indicator 或 "AI 正在思考..." 动画。

### P1 — 影响体验

3. **模式切换缺解释**: "聊天/代理/自动" 三个模式对新用户完全不透明。建议在选项旁加一句话说明，或在首次使用时弹 tooltip 解释区别。

4. **浮动 chat 按钮颜色不协调**: 紫色与整体暖棕色调冲突。建议改为深蓝色或与 primary CTA 同色系。

5. **暗色模式对比度**: 侧栏文字在暗色模式下偏暗，Topic 卡片背景与主背景区分不够。

6. **导航路径重复**: 侧栏"信息源" 和 设置 > "信息源" tab 指向同一页面。建议合并或重命名其中一个。

### P2 — 体验优化

7. **语言一致性**: "Your Research" 标题用英文，其余 UI 全中文 — 建议统一。

8. **Workspace chat panel 偏窄**: 右侧 chat panel 宽度固定，AI 长回复需要大量滚动。建议支持拖拽调整宽度。

9. **材料导入归属默认值**: 添加材料时默认"不归类" — 如果从 workspace 触发，应自动选当前 Topic。

10. **空状态可丰富**: 材料库空状态提到"浏览器插件"但无下载链接；首页空状态可加示例 Topic。
