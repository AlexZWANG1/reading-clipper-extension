## 一、核心数据结构

### 1. Source（信息源）🆕

```typescript
interface Source {
  source_id: string;           // "src_xxx"
  name: string;                // 展示名
  category: string;            // 分类
  importance_level: 1 | 2 | 3; // 重要度（1=最重要）
  url: string | null;          // 入口页
  region: 'overseas' | 'domestic' | 'unknown' | null;
  description: string | null;
  status: 'active' | 'paused' | 'archived';
  created_at: string;
  updated_at: string;
}
```

**存储位置**: `data/sources.json`

---

### 2. Card（卡片）

```typescript
interface Card {
  id: string;                  // "card_xxx"
  source_id: string | null;    // 🆕 关联的 Source ID
  title: string | null;        // 🆕 页面标题
  summary: string;             // AI 摘要
  key_points: string[];        // 要点列表
  raw_snippet: string;         // 原始文本
  source_name: string | null;  // 来源名称
  source_url: string | null;   // 来源 URL
  topic_title: string | null;  // 主题分类
  note: string;                // 用户批注
  image_url: string | null;    // 图片
  created_at: string;
  deleted: boolean;            // 软删除
}
```

**存储位置**: `data/cards.json`

---

### 3. Document（文档）

```typescript
interface Document {
  doc_id: string;
  topic_title: string;
  doc_questions: Question[];
  doc_hypotheses: Hypothesis[];
  story_units: StoryUnit[];
  created_at: string;
  updated_at: string;
}

interface Question {
  id: string;    // "Q1"
  text: string;
}

interface Hypothesis {
  id: string;           // "H1"
  question_id: string;
  text: string;
}

interface StoryUnit {
  unit_id: string;      // "U1"
  title: string;
  core_point: string;
  card_ids: string[];
  question_id?: string;
  hypothesis_id?: string | null;
}
```

**存储位置**: `data/documents.json`

## 二、API 端点

### Source API 🆕

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/sources` | 创建信息源 |
| GET | `/api/sources` | 获取列表 |
| GET | `/api/sources/:id` | 获取详情 |
| PATCH | `/api/sources/:id` | 更新 |
| DELETE | `/api/sources/:id` | 删除 |

### Card API

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/cards/capture` | 创建卡片（支持 source_id, title）|
| GET | `/api/cards` | 获取列表（支持 source_id 筛选）|
| PATCH | `/api/cards/:id` | 更新 |
| DELETE | `/api/cards/:id` | 软删除 |
| POST | `/api/cards/search` | 语义搜索 |
| POST | `/api/cards/generate-title` | AI 生成标题 |

### Document API

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/documents` | 创建空文档 |
| POST | `/api/documents/from-cards` | 从卡片生成文档 |
| GET | `/api/documents` | 获取列表 |
| GET | `/api/documents/:id` | 获取详情 |
| PATCH | `/api/documents/:id` | 更新 |
| DELETE | `/api/documents/:id` | 删除 |

### Topics API

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/topics` | 获取所有主题 |
