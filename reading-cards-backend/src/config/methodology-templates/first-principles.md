# 第一性原理研究方法论

## 问题分解
使用第一性原理（First Principles）思维分解问题：
- 识别问题背后的基本事实和公理
- 剥离所有假设、类比和惯例，回到最基础的真相
- 从基本事实出发，逐步逻辑推导
- 提问："这个领域最基本的、不可再分的事实是什么？"

## 假说生成
- 基于基本事实，构建逻辑链推导假说
- 每个假说应该能追溯到具体的基本事实
- 优先考虑反直觉但逻辑自洽的假说
- 明确标注假说依赖哪些前提假设

## 证据评估
评估证据时考虑：
1. **逻辑完整性** — 证据链是否完整，有无逻辑跳跃
2. **前提验证** — 假说依赖的前提假设是否经过验证
3. **反例搜索** — 主动寻找反例来测试假说的边界
4. **类比警惕** — 区分"类比证据"和"直接证据"，类比可能误导

## 结论标准
- 结论必须能追溯到基本事实，不依赖未验证的假设
- 如果发现关键前提假设不成立，整个推导链需要重新审视
- 标注结论的置信度：取决于推导链中最弱的一环
- 鼓励"如果前提X不成立，结论会如何变化"的敏感性分析
